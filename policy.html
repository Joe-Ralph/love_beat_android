LoveBeat Privacy Policy

Last Updated: December 4, 2024

1. Introduction

Welcome to LoveBeat, a Wear OS app designed to connect couples through intimate, personal interactions. We are committed to protecting your privacy and ensuring the security of your information.

2. Information We Collect

2.1 Minimal Data Collection

  • Unique, randomly generated UUID for app instance
  • Anonymized server connection logs
  • No personal identifying information is collected

3. How We Use Your Information

We use the collected information to:

  • Enable app pairing functionality
  • Facilitate vibration interactions between paired devices
  • Maintain server connectivity
  • Improve overall app performance

4. Pairing Mechanism

  • Pairing is initiated through a secure server
  • Users exchange UUIDs during the pairing process
  • No personal information is stored or transmitted
  • Pairing requires mutual consent from both users

5. Data Transmission

  • Vibration signals are transmitted via secure internet connection
  • Communication is limited to UUID-based device interactions
  • No additional user data is captured during transmission

6. Information Sharing and Disclosure

  • No personal information is shared with third parties
  • Server logs are anonymized and used solely for maintaining service
  • We do not sell or monetize any user data

7. Data Security

We implement security measures to protect your interaction:

  • Encrypted communication channels
  • Randomized UUIDs prevent tracking
  • Minimal data retention
  • No persistent user profiles

8. User Controls

8.1 Pairing

  • Users can unpair by uninstalling the app
  • Pairing requires explicit mutual consent
  • No lasting connection beyond app usage

8.2 Data Management

  • Ability to reset all app data
  • Complete data removal upon app uninstall

9. Data Retention

  • UUIDs are regenerated with each app installation
  • No long-term data storage
  • Server logs are temporarily maintained for service functionality

10. Children's Privacy

LoveBeat is not intended for users under 18. While no personal data is collected, we encourage parental guidance.

11. International Users

  • Service operates through secure internet protocols
  • Complies with minimal data collection principles

12. Changes to This Privacy Policy

  • We may update this policy periodically
  • Significant changes will be communicated via app update
  • Continued use of the app constitutes acceptance of updated terms
